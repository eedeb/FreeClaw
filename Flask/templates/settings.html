Providers

Any OpenAI-compatible chat endpoint. The agent tries your enabled providers in order, top to bottom, falling through to the next if one fails or is rate-limited. Free option: get a Groq API key. Prompt caching needs no setup — FreeClaw sends what each model requires and drops it for any endpoint that objects.

Vision model

Which connected provider handles get_image_description — describing images the agent is asked about. The provider needs a model set in Providers above.

Jev

Optional. With a key from console.typesafe.ai, Jev reads each message first and sends the model only the tools, earlier messages and memory it needs — fewer tokens per turn. Leave it blank and FreeClaw routes messages with its built-in classifier.

MCP servers

Connect external Model Context Protocol servers to give the agent new tools. Remote (HTTP) talks to a hosted server over a URL. Local (stdio) runs a command on this machine and speaks to it over its stdin/stdout — which is how most published MCP servers ship. Adding and removing a server covers the whole install; switching one on is per user, so each person's agent carries only the tools they actually want.

Shell approvals

Every shell command the agent tries to run is put to you for approval first — the agent is never asked and can't approve itself. Commands you marked always allow are listed here and run without prompting; remove one to go back to being asked. These are saved per user, for the current user.

Restart server

Most changes above apply on the next message with no restart. A restart is only needed for a new session secret, an updated dependency, or code pulled by update.sh. The server goes down for a few seconds and this page reloads itself when it's back.
