# Web app + agent dependencies, synced by install.sh and update.sh.
flask
itsdangerous
# >=1.66 for client.responses, which a provider set to the Responses API needs
# (src/responses_api.py). The floor is also what makes an existing install
# actually upgrade — pip leaves an unconstrained requirement alone.
openai>=1.66
httpx
requests
ddgs
beautifulsoup4
json-repair
python-dotenv

# Reading PDFs (src/pdfs.py): read_file's text page by page, and scanned pages
# rendered as images. Prebuilt wheels for Linux, macOS and Windows on x86-64
# and ARM, so nothing compiles. Optional at runtime — without it a PDF is
# answered with "run ./update.sh" instead of the text.
pypdfium2>=4
# Turns a scanned PDF page into the JPEG the model is shown. Without it the
# text still reads and a scanned page says to run ./update.sh.
Pillow

# Tokeniser for the local Classy intent classifier (models/run_model.py).
# It used to arrive indirectly with the old torch-based classifier's dependency
# tree; now that stack is gone it has to be requested outright, or run_model
# fails to import and every turn dies before it reaches the model. The word
# table it needs is a separate download — every installer fetches it, and
# run_model.py falls back to fetching it on first use.
nltk

# ── the shipped browser MCP server (src/mcp_client.py: BUILTIN_SERVERS) ──
#
# The server is FreeClaw's own (src/browser_server.py) and speaks MCP itself,
# so playwright is all it needs. What this does NOT install is Chromium — a few
# hundred MB fetched only if someone switches the server on
# (src/browser_setup.py).
#
# The marker matters: without it, pip fails the whole file on an interpreter
# playwright doesn't support and takes flask and openai down with it, so an
# old Linux box would stop being able to install FreeClaw at all because of a
# server that ships switched off. With it, those installs simply don't get the
# browser, and Settings says why.
playwright; python_version >= "3.10"
